The Learning Path

Eight milestones, committed one skill at a time.

  1. 2015

    Started Programming

    Wrote my first Hello, World! in C++ and got hooked on the logic of loops, pointers, and the particular joy of squashing a segfault at 1 a.m.

    • C++
    • Algorithms
    • OOP Basics
    100%
  2. 2016

    HTML & CSS

    Traded the console for the browser. Learned semantic markup, the box model, and how to fight (then befriend) Flexbox to build my first real web pages.

    • HTML5
    • CSS3
    • Flexbox
    100%
  3. 2017

    JavaScript

    Made pages actually do things. Dove into the DOM, events, closures, and asynchronous code — and finally understood what "callback hell" meant, first-hand.

    • ES6+
    • DOM APIs
    • Async/Await
    100%
  4. 2018

    Responsive Web Design

    Learned to design mobile-first, then scale up. Media queries, fluid grids, and CSS Grid turned "it works on my screen" into "it works on every screen."

    • Media Queries
    • Mobile-First
    • CSS Grid
    100%
  5. 2019

    Git & GitHub

    Stopped naming folders final_v2_REAL.zip forever. Picked up branching, pull requests, and code review — and started actually collaborating on code.

    • Git
    • GitHub
    • Pull Requests
    100%
  6. 2021

    React

    Started thinking in components instead of pages. Hooks, state, and props reshaped how I structure interfaces — and how I reason about UI as data.

    • React
    • Hooks
    • State Mgmt
    90%
  7. 2022

    Portfolio Projects

    Shifted from tutorials to shipping. Built, deployed, and documented real projects — and learned that finishing is a skill of its own.

    • Deployment
    • UI/UX
    • APIs
    85%
  8. 2024 — now
    In Progress

    Looking for Internship

    Polishing my portfolio, sharpening interview skills, and actively looking for a front-end internship to turn everything I've learned into real-world impact.

    • Open to Work
    • Interview Prep
    • Growth Mindset
    60%
